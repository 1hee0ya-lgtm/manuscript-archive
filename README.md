# 원고 보관함

PC와 휴대폰에서 같은 원고를 이어 쓰는 개인용 웹앱. 원고는 Firebase(본인 계정 전용 공간)에 저장되며 이 저장소에는 프로그램 코드만 있다.

- 소스: `src/` · 빌드 결과(GitHub Pages가 보여주는 파일): `docs/`
- 빌드: `npm install && node build.mjs`
- Firebase 설정값: `src/config.js`

## 유튜브 모바일 화면 넣기

1. 회차/부록의 본문 편집 도구에서 **유튜브**를 누른다. 휴대폰에서는 도구줄을 옆으로 밀면 보인다.
2. **영상 이미지**와 댓글의 **프로필 사진**을 선택하고, 작성자·문구·시간·좋아요·답글을 편집한다.
3. **원고에 넣기**를 누른다. 이후 화면 아래 **내용 편집**으로 다시 수정할 수 있다.

- 참고 사진처럼 댓글 창을 펼친 화면과, 영상 제목·채널 정보가 함께 보이는 화면을 선택할 수 있다.
- 전체 화면은 항상 흰색이다. 가로 영상(16:9)/세로 영상(9:16), 사진 맞춤, 재생 시간과 진행률을 바꿀 수 있다.
- 댓글·답글을 추가/삭제하고 댓글 순서를 바꿀 수 있다. 취소하면 원고에 반영되지 않는다.
- 사진은 기기에서 크기를 줄여 원고와 함께 저장한다. 저장·버전 기록·JSON 백업은 사진과 모든 편집 정보를 보존한다.
- TXT는 영상 정보와 댓글을 텍스트로, DOCX는 영상 이미지와 댓글을 문서 요소로 내보낸다.
- 영상 장면을 사진으로 재현하는 원고용 화면이다.

## 수정본 적용

수정본에는 `src/`, `docs/`, `package.json`, `package-lock.json`이 포함되어 있다.
GitHub 저장소에서 해당 파일을 반영한다. 기존 설정이 main 브랜치의 `/docs`를 게시하는 방식이라면 `docs/`가 새 사이트 화면이다.
`src/`와 설치 목록도 함께 보관해야 다음 수정에 사용할 수 있다.

검증용 모의 저장소는 `npm run build:mock`으로 만들 수 있다. 실제 Firebase 원고와 연결되지 않는다.
