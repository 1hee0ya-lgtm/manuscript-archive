# 유튜브 화면 검증 기록

- 텍스트 형식 왕복·기존 서식·HTML 입력 처리 등 자동 검사 7개 통과.
- Chromium에서 사진/프로필 업로드, 댓글/답글, 적용/취소, 재편집, 화면 삭제 후 실행 취소, 복사/붙여넣기 확인.
- 다크 모드 환경에서도 화면이 흰색으로 표시됨.
- 너비 320, 375, 430, 768px에서 편집 창의 가로 넘침 없음.
- 새로고침 후 사진과 댓글이 유지되고, 읽기 모드에도 표시됨.
- TXT, DOCX 및 JSON 백업 내보내기 확인. DOCX 안의 영상 이미지와 프로필 이미지, 댓글·답글 텍스트 확인.
- 실제 배포용 빌드와 모의 저장소 빌드 모두 성공.

저장 검사는 모의 저장소로 진행했다. 사용자의 실제 Firebase 계정에는 접근하거나 데이터를 쓰지 않았다. 기존 Firebase 설정과 저장소 코드는 변경하지 않았다.
